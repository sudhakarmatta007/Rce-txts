# 🤖 Understand AI

> **See it. Understand it. Text it.**

Understand AI is an AI-powered text recognition application that converts **handwritten text from images into clear digital text** using Gemini AI.

Users can upload an image from their gallery or capture one using their camera, and the application extracts the handwritten content into editable digital text.

## ✨ Features

* 📷 Capture text using camera
* 🖼️ Upload images from gallery
* ✍️ Convert handwritten text into digital text
* 🤖 AI-powered text recognition using Gemini
* 🌐 Translate output into:

  * Original
  * Hindi
  * Telugu
* 🔠 Adjust font size
* **Bold text option**
* 📋 Copy extracted text
* 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

* **Frontend:** React
* **Build Tool:** Vite
* **Language:** JavaScript
* **Styling:** CSS
* **AI:** Google Gemini API
* **Deployment:** Vercel

## 🔄 How It Works

```text
Upload Image / Capture Image
            ↓
       Understand AI
            ↓
       Gemini AI
            ↓
   Handwritten Text Detection
            ↓
      Digital Text Output
            ↓
   Translate / Copy / Customize
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project

```bash
cd understand-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Add your Gemini API key

Create a `.env` file and add your Gemini API key.

```env
VITE_GEMINI_API_KEY=your_api_key
```

> ⚠️ Never upload your API key or `.env` file to GitHub.

### 5. Run the project

```bash
npm run dev
```

Open the local development server in your browser.

```text
http://localhost:5173
```

## 🎯 Purpose

Understand AI is designed to make handwritten content easier to **read, digitize, translate, and reuse** using AI.

It can be useful for students, notes, handwritten documents, and other text-based images.
